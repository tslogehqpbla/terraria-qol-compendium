## Overview

Quality of Life Compendium bundles over 50 individual quality-of-life improvements for Terraria into a single configurable mod, including instant chest renaming, improved NPC shop navigation, auto-pause on inventory, bag auto-open, item crafting directly from chests in range, and dozens more small but impactful convenience features.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria QoL Compendium** delivers the features you need in a clean, intuitive package.
